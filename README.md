# CodeAlpha Stock Portfolio Tracker

## Project Overview
A simple Python application that calculates the total
investment value of a stock portfolio using predefined
stock prices.

## Features
- Displays available stock prices.
- Accepts stock symbols and quantities.
- Calculates individual investment values.
- Calculates total portfolio investment.
- Saves portfolio details to a CSV file.
- Handles invalid stock symbols and quantities.

## Technologies Used
- Python 3
- Dictionaries
- Loops and conditional statements
- Basic arithmetic
- CSV file handling

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run:

   python stock_tracker.py
